# Spanish Practice — span019

Based on span008, with 14 infinitives from your irregular preterite exercise: traer, andar, saber, venir, decir, poner, estar, tener, querer, ser, ir, hacer, dar, ver.

Open index.html in a browser; no installation or server is required.

Includes definitions, a 14-question definitions quiz, preterite rules, bilingual conjugation examples, and a 20-question conjugation quiz. A perfect definitions score unlocks the last three lessons. Correct answers advance after two seconds; after a wrong answer, select the highlighted correction to continue.

Includes translation controls, three text sizes, keyboard navigation, and saved display preferences. Lesson progress uses a separate span019 storage key. The rules explain the corrected answers dijeron and dio.

Study online: https://esemmelman.github.io/span019/

GitHub Pages publishes the root of main automatically after pushes.
