# span019 — Present & Preterite

Study online: https://esemmelman.github.io/span019/

Matches span018's study sheet layout with separate present and preterite columns for all six subject forms. Includes these 14 unique infinitives from the supplied exercise, in order: traer, andar, saber, venir, decir, poner, estar, tener, querer, ser, ir, hacer, dar, ver.

Open index.html for offline use. No dependencies or runtime build needed. GitHub Pages publishes the root of main automatically after pushes.

Run node build.js to regenerate index.html from verbs.json and template.html.
